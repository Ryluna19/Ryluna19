## Featured projects

### 🍔 [Farofa do Areias](https://github.com/Ryluna19/PFarofa-do-Areias)

Full-stack food ordering application with separate customer and administrator flows.

* JWT authentication and protected administrative routes
* Customer order creation, tracking, and order history
* Server-side price calculation and validation
* Controlled order status transitions
* PostgreSQL database with structured order records
* Automated tests and GitHub Actions CI

`React` · `TypeScript` · `Node.js` · `Express` · `PostgreSQL` · `JWT` · `Vitest`

### 💰 [FinanTec](https://github.com/Ryluna19/finantec-data-pipeline)

Published personal finance application focused on financial organization, reliable data processing, and user data isolation.

* Public demonstration deployed with Streamlit
* Authentication and financial data separated by user
* Public temporary accounts with a fixed 24-hour lifetime
* Transaction CRUD and CSV, Excel, and OFX imports
* Validation and duplicate detection before persistence
* Monthly budgets, financial goals, profile, and financial indicators
* Remote persistence with Turso/libSQL and local SQLite compatibility
* 455 automated tests with pytest

**[Open the public demonstration](https://finantec-data-pipeline-immggyug2jwy78khudpv2s.streamlit.app/)**

`Python` · `Streamlit` · `pandas` · `Turso/libSQL` · `SQLite` · `pytest` · `ETL`

### 📋 [Job Application Tracker](https://github.com/Ryluna19/PJobApplicationTracker)

Full-stack application for managing job applications throughout the hiring process.

* JWT authentication and protected API routes
* CRUD, dashboard statistics, search, filters, and status updates
* PostgreSQL schema, seed data, validation, and user ownership protection
* Automated API tests with Vitest and Supertest
* GitHub Actions CI running tests on every push

`React` · `Node.js` · `Express` · `PostgreSQL` · `JWT` · `Vitest` · `Supertest`
